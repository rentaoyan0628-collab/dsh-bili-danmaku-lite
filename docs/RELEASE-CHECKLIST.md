# v0.2 发布检查清单

本目录仅准备源码；没有自动安装、运行、测试或上传。

发布前由使用者明确批准后再执行：

- [ ] 确认继承的本机直播代码来源与再分发权；对借用代码保留许可证和署名。
- [ ] 检查发布包仅含源码与文档，无凭据、个人消息、房间授权、备份、模型或venv。
- [ ] 在独立数据目录安装依赖和验证登录，不能读取当前生产数据作为默认。
- [ ] 验证只读默认、未授权房间拒绝、自动发送开关、发送冷却及小时上限。
- [ ] 验证插件停止/下播/撤销授权后的任务清理，断线重连退避。
- [ ] 验证DSH设置页、工具注册、自动陪聊的实际触发与模型预算。
- [ ] 分别验证无QQ与可选QQ模式；明确标记版本和限制。
- [ ] 再决定公开仓库与npm发布名；当前名称是否可用未检查。

不要直接上传旧运行目录，也不要将有敏感历史的目录整体初始化后推送。
