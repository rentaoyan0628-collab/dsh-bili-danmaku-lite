# 隐私与权限

- 默认不监听、不自动发送；仅用户明确授权的房间允许访问。
- Cookie/会话凭据仅存本机运行数据目录，不随插件发布；不要把运行目录提交Git。
- 弹幕、事件与语音转写文本可能包含昵称、UID及发言。模型理解时，这些内容会交给用户选择的模型供应商；本地缓存不等于全部处理都在本地。
- v0.2 不采集直播音视频；v0.4 的「听声音」是**可选、默认关**的：只把直播里的音频流在管道里解码成 PCM 交给本地语音识别，
  **不写入音频文件**，只保留识别出的文字（默认最近 300 秒）。它不读麦克风、不读桌面、不抽帧、不做视觉理解。
- 语音转写文本会在自动陪聊时随提示一起交给用户选择的模型供应商；只开转写、不开自动陪聊则不出本机。
- 自动陪聊需用户主动启用。内容无法保证完全正确，发送弹幕不可保证可撤回。
- 不绕过验证码、账号限制或房间权限；接口失效应暂停。
- 日志清理与保留期以设置和实现为准；发布候选版请勿用于敏感或无人监管场景。
